# Nanečisto · verejná ukážka

Samostatná statická stránka v priečinku `nanecisto/` na GitHub Pages. Všetky odkazy v aplikácii sú relatívne.

`index.html` obsahuje pôvodnú ukážku a vstup do knižnice praxí. `situace.html` ponúka 12 párov modelových prípadov v češtine a slovenčine: 6 KPV a 6 UPV. České sylaby ukotvujú štúdium IVP ČZU; slovenská verzia je jazyková mutácia, nie slovenský študijný plán. Rozhodnutia sú autorský nácvik, nie potvrdenie profesnej spôsobilosti.

Výsledky používateľa zostávajú v jeho prehliadači. Táto statická stránka neodosiela výskumné dáta na server. Pracovný Word dokument nie je súčasťou verejného repozitára.
